# Hushållsbudgeten (G11)

Utkast.

## Krav på körmiljö

Node.js 22 LTS. Inget annat behöver installeras.

## Starta

```
node src/ui/server.js
```

Öppna sedan http://localhost:3000 i webbläsaren.

## Köra testerna

```
node --test
```

Fylls i under K5. Filen är `data/hushall.txt`.
